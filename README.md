

Only used to generate validation data for onix from visualize.py

The input files ("reference_onix...") are in visualize/parameters, visualize.py has been modified to force the source location and the hit sequence when relevant. 
Running visualize.py will save the trajectory to a file, e.g., 
```bash
python visualize/visualize.py -i reference_onix_zero_hit_1d
```

The policy is chosen manually by editing the input file.
